# Trabajo colaborativo con GitHub Desktop

1. Mantener `.gitignore` en la raíz.
2. No incluir `.vs`, `bin`, `obj`, secretos ni contraseñas.
3. Cada integrante trabaja en una rama, por ejemplo `feature/citas`, `feature/persistencia`.
4. Commits pequeños y descriptivos: `Add PetCareDbContext`, `Add cita validation`.
5. Hacer Pull antes de comenzar y Push al terminar.
6. Crear Pull Request y revisar conflictos antes de integrar.
7. Compartir migraciones, `.cs`, `.csproj`, `.sln` y documentación; no compartir archivos locales generados.
